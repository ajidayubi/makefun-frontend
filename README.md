# make.fun frontend

[![make.fun](https://make.fun/badge/makefun-frontend-01)](https://make.fun/bounty/makefun-frontend-01)
[![Built for make.fun](https://make.fun/badge)](https://make.fun)

A fast, read-only frontend for make.fun's live competition board, bounty details, standings and maker profiles. It uses static files and the public make.fun API.

Referral code: `cbk8hpf3`

## Run

Requires Node.js 22.18 or later.

```sh
node serve.ts
```

Open http://127.0.0.1:8080.

Build the hand-in dossier with `MAKEFUN_OUTPUT_DIR=out node main.ts`.
